# 方法與模型卡

本文件說明 CPBL Scouting Lab 每一個估計與模擬怎麼計算、做了哪些假設，以及什麼情況下不應使用結果。所有方法都在 `src/analytics/`（Python）與 `web/src/lib/`（TypeScript）中自行實作，並有對應的單元測試。

## 適用範圍

- 用於探索 CPBL 官方公開的賽季彙總資料。
- 用於展示統計推論、模擬、資料工程與前端產品化。
- **不**預測比賽勝負、球員未來成績或受傷風險；**不**提供投注、薪資、交易或先發決策建議。

## 資料

資料只來自 CPBL 官方公開頁面（球員名單、球隊戰績、打者與投手全記錄），經 `run_all.py --mode api` 擷取、清理與品質檢查，並以 SHA-256 記錄在 `reports/metrics/public_release_manifest.json`。`player_id` 全程以字串保存，避免前導零遺失。

## 1. 真實實力估計（Empirical Bayes）

| 項目 | 說明 |
| --- | --- |
| 模型 | 每個比率視為二項結果：打者上壘率、三振率、保送率、全壘打率（分母為打席）；投手三振率、保送率、被全壘打率（分母為面對打者 ≈ 出局數＋安打＋保送） |
| 先驗 | 以達門檻球員（打者 50 打席、投手 15 局）用動差法估計 Beta(α, β)：觀察到的變異扣除平均二項雜訊 μ(1−μ)/n 後才是真實天分的變異；集中度限制在 [2, 5000] |
| 後驗 | Beta(α + 成功, β + 失敗)；回報後驗平均與 80% 等尾可信區間（不完全 Beta 函數以 Lentz 連分數實作，反函數以二分法求解） |
| 上壘率分子 | 官方上壘率 × 打席，因此包含觸身球 |
| 投手 FIP | 由收縮後的三振、保送、被全壘打率換算：(13·HR + 3·BB − 2·K) × (聯盟 BF/IP) + 常數；常數讓聯盟 FIP 等於聯盟 ERA |
| 測試保證 | 後驗介於原始值與聯盟平均之間；樣本越大區間越窄；樣本為 0 時等於先驗；CDF 與封閉解一致 |

**限制**：先驗把所有球員視為來自同一分布，沒有考慮守位、年齡或球場；收縮後的值是「目前最可信的估計」，不是未來預測。

## 2. 打線實驗室（Monte Carlo）

- **事件**：一壘安打、二壘安打、三壘安打、全壘打、保送／觸身、三振、其他出局。觸身球由「官方上壘率推回的上壘次數 − 安打 − 保送」估計後併入保送。
- **收縮**：打者事件次數先加 120 個聯盟平均打席；投手加 150 名聯盟平均打者，再正規化成機率。
- **對戰**：廣義 log5，P(事件) ∝ 打者機率 × 投手機率 ÷ 聯盟機率。
- **跑壘推進**（固定、公開的機率）：二壘跑者遇一壘安打回本壘 60%；一壘跑者遇一壘安打上三壘 28%；一壘跑者遇二壘安打回本壘 42%；少於兩出局時高飛犧牲打 45%、二壘跑者推進 35%、一壘跑者推進 25%、雙殺 12%；失誤上壘 2.5%。
- **校準**：聯盟平均打線模擬 20,000 場平均 3.69 分，實際聯盟每場 3.79 分（差 2.6%，單元測試要求 ±20%）。
- **棒次搜尋**：最陡上升的兩兩對調，每個候選以相同的逐場亂數種子（common random numbers）搜尋 1,500 場。建議固定後，另以未參與搜尋的亂數序列模擬 1,500 場配對評估原打線與建議打線，回報差異的 95% 信賴區間；跨零時提醒可能只是雜訊，整段低於零時明示調整後得分較低。
- **可重現**：mulberry32 亂數產生器加上逐場衍生種子，同一打線與種子永遠得到相同結果。

**限制**：不模擬守備、盜壘、牽制、換投、延長賽、球場與左右投打；適合比較不同打線的相對差異，不適合預測單場比分。

## 3. 季末戰績模擬

- **強度**：畢氏期望勝率（指數 1.83），只看得失分。
- **單場勝率**：log5(p_A, p_B)。
- **賽程**：官方剩餘賽程不在公開快照中，因此假設本段賽季每隊 60 場（中職半季制），以「剩餘場數最多的兩隊、交手次數最少者優先」的確定性方式配對；剩餘場數不平衡或總數為奇數而配不到的場次，改對聯盟平均對手（勝率即該隊自身強度）模擬，確保每隊模擬場數等於剩餘場數。
- **模擬**：10,000 次（種子 20261024）；依勝率排名（和局不計），同勝率並列第一時平分機率，因此各隊奪冠機率總和恰為 1。

**限制**：強度在剩餘賽程中固定不變，不考慮傷兵、輪值與主客場；配對規則只是近似。

## 4. 球員檔案

- **百分位**：與達門檻的同類型球員比較，方向依指標而定（例如三振率越低越好），同值取中間名次。
- **軌跡**：跨 17 份官方快照的 OPS（打者）或 ERA（投手）；最小平方斜率與期間變化，變化需超過 0.030 OPS／0.50 ERA 才判讀為上升或下滑。
- **相似球員**：標準化指標的餘弦相似度；每項特徵的貢獻 z_i·z_j／(‖a‖‖b‖) 加總即為相似度，因此能解釋「為什麼像」。
- **自動球探摘要**：規則挑選強項（≥ PR 80）、弱點（≤ PR 20）、小樣本落差（原始值與收縮後差距 ≥ 0.025）、趨勢與最相似球員；每一句都記錄它依據的指標，並由測試保證沒有未填入的模板變數。

## 5. 不應該怎麼用

- 不是官方數據服務，也不是即時戰績；網站會顯示資料年齡。
- 不把模擬機率解讀成校準過的預測，也不拿來下注或做商業決策。
- 小樣本球員的估計區間很寬，請同時看區間而不只看點估計。
